Pengaturan lanjutan (relay CORS)

Browser kadang diblokir CORS saat manggil API SteamGridDB langsung. Kalau nanti muncul error koneksi, isi prefix relay proxy di sini (kosongkan kalau nggak perlu). Permintaan bakal lewat proxy ini, jadi cuma pakai proxy yang kamu percaya.
